# Changelog

All notable changes to Sonora are documented here.

## 1.1.0 - 2026-08-10

- Added silent video-stream downloads at 720p, 1080p, and best quality.
- Added optional audio/video merging.
- Added manual and automatic caption discovery with language selection.
- Added local, deterministic caption punctuation and paragraph formatting.
- Added a liquid-glass interface with automatic light and dark modes.
- Added native macOS and Electron-based Windows desktop wrappers.
- Added one-click Windows build scripts.

## 1.0.0 - 2026-08-09

- Initial audio extraction release with MP3, M4A, and OPUS support.
